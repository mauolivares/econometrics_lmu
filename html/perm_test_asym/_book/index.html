Asymptotic vs. Permutation Inference

Author

Mauricio Olivares

Published

May 19, 2026

Overview

In this note we investigate the asymptotic behavior of the permutation test in the one-sample inference problem when we want to carry out inference for the mean of a random variable. We will consider sign changes as the group transformation and study the behavior of the permutation test and its relationship to the normal approximation when the sample size grows to infinity. We will pay particular attention to what happens when the randomization hypothesis fails.

0.1 The Central Question

In Chapter 4 we construct a permutation test for the one-sample hypothesis

\[H_0 : \mathbb{E}[W] = 0\]

using sign changes as the group of transformations. Recall that the randomization hypothesis is the key condition that guarantees finite-sample exactness of the permutation test. It will require that the distribution of \(W\) to be symmetric about zero. When the DGP is skewed, this condition fails, and the permutation test is no longer exact. It remains, however, asymptotically valid if we modify the test statistic as we showed in class.

This raises a natural question: if both the sign-change permutation test and the standard normal approximation are only asymptotically valid under a skewed DGP, how do their finite-sample null distributions compare? Chapter 5 answers this question by simulating both distributions under a re-centred exponential DGP, which satisfies \(\mathbb{E}[W] = 0\) but is right-skewed.

ImportantKey Message

The sign-change permutation test is exact if and only if the distribution of \(W\) is symmetric about zero. Under a skewed DGP, both the permutation test and the normal approximation are only asymptotically valid. The permutation test is not a free lunch: its finite-sample guarantees rest on the randomization hypothesis, which is a substantive assumption about the DGP.
