4 The Sign-Change Permutation Test

4.1 The Sign-Change Group

In the two-sample problem of the previous notes, the group \(\mathbf{G}_n\) consisted of all permutations of the treatment vector. For the one-sample problem, the natural group is instead the set of all sign changes.

ImportantDefinition: Sign-Change Group

Let \(\boldsymbol{\epsilon} = (\epsilon_1, \ldots, \epsilon_n) \in \{-1, +1\}^n\). The sign-change group is

\[\mathbf{G}_n = \left\{ g_{\boldsymbol{\epsilon}} : g_{\boldsymbol{\epsilon}} W^{(n)} = (\epsilon_1 W_1, \ldots, \epsilon_n W_n) \right\},\]

with cardinality \(M = \#\mathbf{G}_n = 2^n\).

Each element of \(\mathbf{G}_n\) flips the sign of a subset of observations while leaving their absolute values unchanged. Since \(M = 2^n\) grows exponentially in \(n\), exact enumeration is infeasible even for moderate sample sizes; we therefore draw \(B\) elements of \(\mathbf{G}_n\) uniformly at random.

4.2 The Randomization Hypothesis

Recall the general framework from the previous notes. The permutation test is finite-sample exact at level \(\alpha\) if the law \(P_n\) satisfies the randomization hypothesis with respect to \(\mathbf{G}_n\):

\[W^{(n)} \stackrel{d}{=} g_{\boldsymbol{\epsilon}}\, W^{(n)} \quad \forall\, g_{\boldsymbol{\epsilon}} \in \mathbf{G}_n, \quad \text{whenever } P_n \in \Omega_0.\]

For the sign-change group, this condition requires that the joint distribution of \((W_1, \ldots, W_n)\) is invariant under arbitrary sign flips of its coordinates. Under i.i.d. sampling, this reduces to the requirement that the marginal distribution of each \(W_i\) be symmetric about zero:

\[W_i \stackrel{d}{=} -W_i.\]

WarningThe Randomization Hypothesis Fails Here

The re-centred exponential \(W_i = \text{Exp}(1) - 1\) has \(\mathbb{E}[W_i] = 0\) but is right-skewed (skewness \(= +2\)). It is not symmetric about zero, so

\[W_i \stackrel{d}{\neq} -W_i,\]

and the randomization hypothesis does not hold. The sign-change permutation test is therefore not exact for this DGP. Both the permutation test and the normal approximation are only asymptotically valid. Their finite-sample behaviour is compared in Chapter 5.

The precise relationship between the null hypothesis and the randomization hypothesis is worth stating explicitly:

Condition Randomization hyp. holds? Test is exact?
\(P\) symmetric about 0 Yes Yes
\(P\) satisfies \(\mathbb{E}[W]=0\), asymmetric No No (asymptotic only)

4.3 Applying the Sign-Change Group

The function group.action() from the function library implements the Monte Carlo approximation: it draws \(B\) elements of \(\mathbf{G}_n\) uniformly at random and returns an \(n \times B\) matrix whose \(b\)-th column is \(g_{\boldsymbol{\epsilon}^{(b)}} W^{(n)}\).

Apply B random sign changes to W_n 
W_n_perm <- group.action(W_n, B, type = "sign.changes")

# W_n_perm is an n x B matrix; column b is the b-th sign-changed sample
dim(W_n_perm)
[1] 1000  499

4.4 Recomputing \(T_n\) Over Sign Changes

For each column \(b = 1, \ldots, B\) we recompute the studentised statistic on the sign-changed data:

Compute permuted test statistics 
Tn_perm <- apply(W_n_perm, 2, function(x) Tn(x, n, studentized = TRUE))

The collection \(\{T_n(g_{\boldsymbol{\epsilon}^{(b)}} W^{(n)})\}_{b=1}^{B}\) approximates the randomization distribution of \(T_n\) under \(\mathbf{G}_n\).

4.5 The Permutation Critical Value

Fix \(\alpha \in (0,1)\). Stack the \(B\) permuted statistics with the observed statistic and sort them:

\[T_n^{(1)}(w) \leq T_n^{(2)}(w) \leq \cdots \leq T_n^{(B+1)}(w).\]

Define \(k = (B+1) - \lfloor (B+1)\alpha \rfloor\). The permutation critical value is

\[\hat{c}_n(1-\alpha) = T_n^{(k)}(w).\]

Compute the permutation critical value 
Tn_all <- c(Tn_perm, Tn_obs)
k      <- length(Tn_all) - floor(length(Tn_all) * alpha)
cv_perm <- sort(Tn_all)[k]

cat("Permutation critical value:", round(cv_perm, 4), "\n")
Permutation critical value: 1.7509
Compute the permutation critical value 
cat("Normal critical value z_{1-alpha}:", round(qnorm(1 - alpha), 4), "\n")
Normal critical value z_{1-alpha}: 1.6449

4.6 The Permutation Test Decision

The one-sided permutation test rejects \(H_0\) whenever the observed statistic exceeds the permutation critical value:

\[\phi_n^{\text{perm}} = \mathbf{1}\left\{ T_n > \hat{c}_n(1-\alpha) \right\}.\]

Apply the permutation test 
result <- perm_test(Tn_all, alpha)
cat("Reject H0 (1 = yes, 0 = no):", result, "\n")
Reject H0 (1 = yes, 0 = no): 0

4.7 The Permutation P-Value

An equivalent summary is the permutation p-value

\[\hat{p} = \frac{1}{B+1} \sum_{b=1}^{B+1} \mathbf{1}\!\left\{ T_n^{(b)}(w) \geq T_n(w) \right\},\]

where the sum includes the observed statistic itself as the \((B+1)\)-th element.

Compute the permutation p-value 
p_perm <- mean(Tn_all >= Tn_obs)
cat("Permutation p-value:", round(p_perm, 4), "\n")
Permutation p-value: 0.422

```{r}
#| label: setup-ch2
#| include: false

rm(list = ls())
library(ggplot2)
source("../../programs/ACA_Function_Library.r")
set.seed(42, kind = "L'Ecuyer-CMRG")

n     <- 1000
B     <- 499
alpha <- 0.05

Tn <- function(data, sample_size, studentized = FALSE) {
  if (studentized) return(mean(data) / sqrt(var(data) / sample_size))
  return(sqrt(sample_size) * mean(data))
}

W_n    <- rexp(n, rate = 1) - 1
Tn_obs <- Tn(W_n, n, studentized = TRUE)
```
