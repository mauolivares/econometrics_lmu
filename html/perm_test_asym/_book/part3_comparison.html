5 Finite-Sample Comparison

5.1 Two Asymptotically Valid Procedures

As established in Chapter 4, neither the sign-change permutation test nor the normal approximation is exact for the re-centred exponential DGP, because the randomization hypothesis fails. Both procedures are, however, asymptotically valid under \(H_0 : \mathbb{E}[W] = 0\), in the sense that

\[\lim_{n \to \infty} \mathbb{P}_{H_0}\!\left[\phi_n^{\text{perm}} = 1\right] = \alpha, \qquad \lim_{n \to \infty} \mathbb{P}_{H_0}\!\left[\phi_n^{\text{asy}} = 1\right] = \alpha,\]

where \(\phi_n^{\text{asy}} = \mathbf{1}\{T_n > z_{1-\alpha}\}\) and \(z_{1-\alpha} = \Phi^{-1}(1-\alpha)\) is the \((1-\alpha)\)-quantile of \(\mathcal{N}(0,1)\).

The question is: how do the two procedures compare in finite samples? We answer this by simulating the randomization distribution (via sign changes applied to the observed \(W^{(n)}\)) and the asymptotic null distribution (by drawing fresh samples from \(\mathcal{N}(0,1)\), which is what \(T_n\) converges to under \(H_0\)), and comparing both to the \(\mathcal{N}(0,1)\) reference.

5.2 Simulating the Asymptotic Null Distribution

Under \(H_0\), the CLT guarantees \(T_n \xrightarrow{d} \mathcal{N}(0,1)\). We approximate this limiting distribution by drawing \(B\) independent samples of size \(n\) from \(\mathcal{N}(0,1)\) directly and computing \(T_n\) on each:

Simulate the asymptotic null distribution 
simulated_asymtest <- numeric(B)

for (i in seq_len(B)) {
  W_asym             <- rnorm(n, mean = 0, sd = 1)
  simulated_asymtest[i] <- Tn(W_asym, n, studentized = TRUE)
}

Tn_all_asym <- c(simulated_asymtest, Tn_obs)
Note

Drawing from \(\mathcal{N}(0,1)\) rather than from the true DGP (the re-centred exponential) is deliberate: the \(\mathcal{N}(0,1)\) samples represent the limiting distribution that \(T_n\) converges to, i.e. the distribution the normal approximation implicitly assumes. Comparing the randomization distribution against this reference directly shows how well the normal approximation characterises the finite-sample behaviour of \(T_n\).

5.5 Interpreting the Comparison

Several features of the plot deserve attention.

Shape of the randomization distribution. The randomization distribution is obtained by applying sign changes to the observed sample \(W^{(n)}\). Because the re-centred exponential is right-skewed, the observed sample itself is skewed, and this skewness is inherited by the randomization distribution. The distribution therefore does not centre exactly on zero and may deviate from the \(\mathcal{N}(0,1)\) reference in the tails.

Shape of the asymptotic distribution. The simulated asymptotic distribution is generated by drawing fresh \(\mathcal{N}(0,1)\) samples and computing \(T_n\) on each. Because these samples are symmetric, the resulting distribution of \(T_n\) closely tracks the \(\mathcal{N}(0,1)\) reference, as expected.

Discrepancy between the critical values. When the two critical values differ, the two tests will reach different rejection decisions for the same observed \(T_n\). This discrepancy reflects the finite-sample cost of using the sign-change permutation test under a DGP for which the randomization hypothesis fails.

TipTakeaway

When the randomization hypothesis holds (symmetric DGP), the sign-change permutation test is exact and the normal approximation is only asymptotically valid — the permutation test strictly dominates. When the randomization hypothesis fails (skewed DGP), both tests are asymptotically valid, and the comparison reduces to a finite-sample question about which critical value is closer to the true \((1-\alpha)\) quantile of the null distribution of \(T_n\). There is no theoretical guarantee that the permutation test is better in this case.

5.6 Exactness Under the Randomization Hypothesis

For completeness, we restate the exactness theorem from the previous notes in the current context.

TipTheorem (Finite-Sample Exactness)

If \(P_n \in \Omega_0\) satisfies the randomization hypothesis with respect to \(\mathbf{G}_n\), then

\[\mathbb{E}\!\left[\phi_n^{\text{perm}}\!\left(W^{(n)}\right)\right] = \alpha \quad \text{for all } P_n \in \Omega_0.\]

Under the re-centred exponential, the precondition of this theorem — the randomization hypothesis — does not hold. Exactness is therefore not guaranteed, and the result above does not apply.

# Finite-Sample Comparison {#sec-comparison}

```{r}
#| label: setup-ch3
#| include: false
#| message: false

rm(list = ls())
library(ggplot2)
source("../../programs/ACA_Function_Library.r")
set.seed(42, kind = "L'Ecuyer-CMRG")

n     <- 1000
B     <- 499
alpha <- 0.05

Tn <- function(data, sample_size, studentized = FALSE) {
  if (studentized) return(mean(data) / sqrt(var(data) / sample_size))
  return(sqrt(sample_size) * mean(data))
}

W_n      <- rexp(n, rate = 1) - 1
Tn_obs   <- Tn(W_n, n, studentized = TRUE)

W_n_perm <- group.action(W_n, B, type = "sign.changes")
Tn_perm  <- apply(W_n_perm, 2, function(x) Tn(x, n, studentized = TRUE))
Tn_all   <- c(Tn_perm, Tn_obs)
k        <- length(Tn_all) - floor(length(Tn_all) * alpha)
cv_perm  <- sort(Tn_all)[k]
cv_asym  <- qnorm(1 - alpha)
```
