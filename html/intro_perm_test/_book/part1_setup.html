3 Setup and Data Generation

3.1 Environment

We begin by clearing the workspace and loading the project-specific function library. The library provides, among other things, the gen_data_PO() and group.action() functions that are central to these notes.

Load libraries and function library 
rm(list = ls())

# Load required packages
library(ggplot2)

# Source the function library from the programs directory
source("../../programs/ACA_Function_Library.r")

# Set seed for reproducibility (L'Ecuyer-CMRG for parallel safety)
set.seed(42, kind = "L'Ecuyer-CMRG")
Note

The seed is fixed with the L’Ecuyer-CMRG generator. This generator is safe for parallel execution (e.g., parallel::mclapply) and ensures reproducibility across sessions.

3.2 Potential Outcomes Framework

The data-generating process follows a location-scale model for potential outcomes:

\[Y_i(0) \sim F, \qquad Y_i(1) = Y_i(0) + \tau_i,\]

where the individual treatment effect is

\[\tau_i = \mu_\tau + \sigma_\tau \cdot Y_i(0).\]

Setting \(\mu_\tau = 0\) and \(\sigma_\tau = 0\) imposes the sharp null hypothesis of no treatment effect:

\[H_0 : Y_i(1) = Y_i(0) \quad \text{a.s.} \quad \Longleftrightarrow \quad Y \perp D.\]

Treatment is assigned completely at random with probability \(p = 0.5\), so \(\{(Y_i(1), Y_i(0))\}_{i=1}^n \perp \{D_i\}_{i=1}^n\).

Generate data under the sharp null 
# Generate data under the sharp null (te.mean = te.sd = 0)
data <- gen_data_PO(
  n      = 100,
  te.mean = 0,
  te.sd   = 0,
  p       = 0.5,
  type    = "normal"
)

3.3 Visualising the Potential Outcomes

Under the sharp null \(Y_i(1) = Y_i(0)\), the marginal distributions of the treated and control outcomes should look similar. We can verify this:

Plot density of observed outcomes by treatment arm 
Y_treated <- data$Y[data$D == 1]
Y_control <- data$Y[data$D == 0]

df_plot <- data.frame(
  value = c(Y_treated, Y_control),
  group = factor(
    c(rep("Treated (D=1)", length(Y_treated)),
      rep("Control (D=0)", length(Y_control)))
  )
)

ggplot(df_plot, aes(x = value, fill = group)) +
  geom_density(alpha = 0.5) +
  scale_fill_manual(values = c("steelblue", "tomato")) +
  labs(
    x     = "Outcome Y",
    y     = "Density",
    fill  = NULL,
    title = "Observed Outcomes by Treatment Arm"
  ) +
  theme_minimal(base_size = 13)

As expected, the two distributions are nearly indistinguishable when the sharp null holds.

## Visualising the Potential Outcomes

Under the sharp null $Y_i(1) = Y_i(0)$, the marginal distributions of
the treated and control outcomes should look similar. We can verify this:

```{r}
#| label: fig-po-density
#| fig-cap: "Kernel density estimates of the observed outcomes by treatment arm under the sharp null."
#| code-summary: "Plot density of observed outcomes by treatment arm"

Y_treated <- data$Y[data$D == 1]
Y_control <- data$Y[data$D == 0]

df_plot <- data.frame(
  value = c(Y_treated, Y_control),
  group = factor(
    c(rep("Treated (D=1)", length(Y_treated)),
      rep("Control (D=0)", length(Y_control)))
  )
)

ggplot(df_plot, aes(x = value, fill = group)) +
  geom_density(alpha = 0.5) +
  scale_fill_manual(values = c("steelblue", "tomato")) +
  labs(
    x     = "Outcome Y",
    y     = "Density",
    fill  = NULL,
    title = "Observed Outcomes by Treatment Arm"
  ) +
  theme_minimal(base_size = 13)
```

As expected, the two distributions are nearly indistinguishable when the
sharp null holds.
