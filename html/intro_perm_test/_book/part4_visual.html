6 Permutation Test: A Visual Walk-Through

6.1 Setup and Notation

Throughout this chapter we work with the two-sample problem introduced in Chapter 4. For clarity, we use the difference-in-means as the test statistic, not the difference-in-variance. As we argue during lecture, the construction of the permutation test does not depend on the choice of the test statistic. We only do it because it makes the visual the easiest to digest. Indeed, the same construction applies verbatim to any real-valued \(T_n\), including the variance-ratio statistic Tn_stat_variance() used in earlier chapters.

Concretely, let

\[W^{(N)} = (X_1, \ldots, X_m,\, Y_1, \ldots, Y_n)\]

be two independent samples with \(m = 10\), \(n = 12\), and \(N = m + n = 22\). Recall we seek to test

\[H_0 : P_X = P_Y \quad \text{vs} \quad H_1 : P_X \neq P_Y,\]

but this time using the test statistic

\[T_n\!\left(W^{(N)}\right) = \bar{X} - \bar{Y}, \qquad \bar{X} = \frac{1}{m}\sum_{i=1}^{m} X_i, \quad \bar{Y} = \frac{1}{n}\sum_{j=1}^{n} Y_j.\]

Under the randomization hypothesis, if \(H_0\) holds then \(W^{(N)}\) and \(g W^{(N)}\) share the same distribution for every \(g \in \mathbf{G}_n\), where \(\mathbf{G}_n\) is the group of all permutations of \(\{1, \ldots, N\}\). This means we can generate auxiliary realizations \(T_n(g_b W^{(N)})\), \(b = 1, \ldots, B\), and use their empirical distribution as an approximation to the null distribution of \(T_n\).

6.3 What the Widget Illustrates

The five steps map directly onto the computational procedure summarised in Chapter 4:

Widget step Formal object
Original samples \(W^{(N)} = (X_1,\ldots,X_m,Y_1,\ldots,Y_n)\)
Observed \(T_n\) \(T_n(W^{(N)}) = \bar{X} - \bar{Y}\)
Permutation \(b\) \(g_b W^{(N)}\), new split into groups of size \(m\) and \(n\)
Permuted statistic \(T_n(g_b W^{(N)})\)
Null distribution \(\{T_n(g_b W^{(N)})\}_{b=1}^{B}\), with \(\hat{p}\) reported
NoteRemark on the choice of \(T_n\)

The widget uses \(T_n = \bar{X} - \bar{Y}\) for expository clarity. The permutation procedure — pool, reshuffle, recompute, repeat — is identical regardless of the test statistic. In Chapter 4 and Chapter 5 we use the studentized variance-ratio statistic Tn_stat_variance(), which is better suited to testing \(H_0 : \mathrm{Var}[Y(1)] = \mathrm{Var}[Y(0)]\).

TipKey Takeaway

Under \(H_0 : P_X = P_Y\), permuting the labels does not change the distribution of \(W^{(N)}\). Consequently, \(T_n(W^{(N)})\) and \(T_n(g_b W^{(N)})\) are identically distributed, and the empirical quantiles of \(\{T_n^{(b)}\}_{b=1}^{B}\) provide a valid (finite-sample exact) null distribution.

const VW = 260, VH = 190, PAD = 22;

function makeDotPositions(n) {
  const cols  = Math.ceil(Math.sqrt(n * 1.5));
  const rows  = Math.ceil(n / cols);
  const cellW = (VW - 2*PAD) / cols;
  const cellH = (VH - 2*PAD) / rows;
  let lcg = 987654321;
  const rand = () => {
    lcg = (Math.imul(lcg, 1664525) + 1013904223) >>> 0;
    return lcg / 0xffffffff;
  };
  return Array.from({length: n}, (_, i) => {
    const col = i % cols, row = Math.floor(i / cols);
    return [
      PAD + cellW * (col + 0.15 + 0.70 * rand()),
      PAD + cellH * (row + 0.15 + 0.70 * rand())
    ];
  });
}

  }

  if (html) { bannerEl.innerHTML = html; bannerEl.classList.add("visible"); }
  else         bannerEl.classList.remove("visible");

  // Buttons
  document.getElementById("btn-prev").disabled = (step === 0);
  document.getElementById("btn-next").disabled = (step === TOTAL_STEPS - 1);

## What the Widget Illustrates

The five steps map directly onto the computational procedure summarised
in @sec-permtest:

| Widget step | Formal object |
|-------------|---------------|
| Original samples | $W^{(N)} = (X_1,\ldots,X_m,Y_1,\ldots,Y_n)$ |
| Observed $T_n$ | $T_n(W^{(N)}) = \bar{X} - \bar{Y}$ |
| Permutation $b$ | $g_b W^{(N)}$, new split into groups of size $m$ and $n$ |
| Permuted statistic | $T_n(g_b W^{(N)})$ |
| Null distribution | $\{T_n(g_b W^{(N)})\}_{b=1}^{B}$, with $\hat{p}$ reported |

::: {.callout-note}
## Remark on the choice of $T_n$

The widget uses $T_n = \bar{X} - \bar{Y}$ for expository clarity.
The permutation procedure — pool, reshuffle, recompute, repeat — is
**identical** regardless of the test statistic. In @sec-permtest and
@sec-simulation we use the studentized variance-ratio statistic
`Tn_stat_variance()`, which is better suited to testing
$H_0 : \mathrm{Var}[Y(1)] = \mathrm{Var}[Y(0)]$.
:::

::: {.callout-tip}
## Key Takeaway

Under $H_0 : P_X = P_Y$, permuting the labels does not change the
distribution of $W^{(N)}$. Consequently, $T_n(W^{(N)})$ and
$T_n(g_b W^{(N)})$ are identically distributed, and the empirical
quantiles of $\{T_n^{(b)}\}_{b=1}^{B}$ provide a valid
(finite-sample exact) null distribution.
:::
